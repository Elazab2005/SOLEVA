# SOLEVA — AI Product Photography Demo

This folder contains 15 individually cropped AI-generated footwear concept images for the SOLEVA portfolio/demo catalog.

## Files
- `assets/photography/ai-products/` — 15 JPEG images.
- Images are generated concept/reference visuals, not verified photographs of manufactured SOLEVA products.
- Do not make claims that these are actual stock items or exact SKU representations.
- Use one image per existing product ID for the demo; preserve existing prices, sizes, cart, wishlist, and checkout behavior.
